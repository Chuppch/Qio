# AI Agent 配置编排系统 - 技术亮点

## 项目简介

这是一个基于可视化拖拽的**智能体配置编排系统**，通过图形化界面配置 Agent、Client、Model、Prompt 等组件的层级关系和参数，最终生成 JSON 配置数据供后端使用。

## 核心技术亮点

### 1. 智能复制粘贴系统

**位置**: `src/shortcuts/copy/` 和 `src/shortcuts/paste/`

**功能描述**:
实现了复杂的节点复制粘贴功能，支持单个或多个节点的复制，粘贴时自动处理 ID 冲突和引用关系。

**技术亮点**:
- **ID 去重算法**: 使用 nanoid 生成唯一 ID，避免粘贴时的 ID 冲突
- **递归遍历处理**: 递归遍历整个 JSON 结构，替换所有节点 ID、边引用、变量引用
- **智能位置计算**: 根据鼠标位置和原节点边界自动计算粘贴偏移
- **容器节点支持**: 支持在容器节点内粘贴

**核心代码**:
```typescript
// 生成节点 ID 替换映射
export const generateNodeReplaceMap = (
  nodeIds: string[],
  isUniqueId: (id: string) => boolean
): Map<string, string> => {
  const nodeReplaceMap = new Map<string, string>();
  nodeIds.forEach((id) => {
    if (!isUniqueId(id)) {
      let newId: string;
      do {
        newId = generateUniqueId();
      } while (!isUniqueId(newId));
      nodeReplaceMap.set(id, newId);
    }
  });
  return nodeReplaceMap;
};

// 递归遍历并替换所有 ID 引用
traverse(json, (context) => {
  // 处理节点 ID、边引用、变量引用
  if (nodeReplaceMap.has(node.value)) {
    context.setValue(nodeReplaceMap.get(node.value));
  }
});
```

**业务价值**: 提升配置效率，支持快速复制已有配置模板

### 2. 配置流程可视化演示

**位置**: `src/services/running-service.ts`

**功能描述**:
通过图遍历算法验证配置的可达性，从 Start 节点开始遍历所有可达节点，并提供视觉反馈。

**技术亮点**:
- **图遍历算法**: 使用深度优先遍历（DFS）递归访问子节点和连接节点
- **可达性验证**: 发现从 Start 无法到达的"孤立节点"，帮助用户发现配置问题
- **视觉反馈**: 节点逐个高亮（1秒间隔），线条流动效果
- **异步执行**: 使用 Promise 和 delay 实现异步遍历

**核心代码**:
```typescript
async addRunningNode(node: WorkflowNodeEntity): Promise<void> {
  this._runningNodes.push(node);
  node.renderData.node.classList.add('node-running'); // 高亮节点
  this.document.linesManager.forceUpdate(); // 刷新线条
  await delay(RUNNING_INTERVAL);
  
  // 遍历子节点（嵌套配置）
  await Promise.all(node.blocks.map((nextNode) => this.addRunningNode(nextNode)));
  
  // 遍历连接节点
  const nextNodes = node.getData(WorkflowNodeLinesData).outputNodes;
  await Promise.all(nextNodes.map((nextNode) => this.addRunningNode(nextNode)));
}
```

**业务价值**: 
- 验证配置完整性：发现未连接的节点
- 理解配置结构：可视化展示多层级嵌套关系
- 提升配置质量：在保存前发现配置问题

### 4. 变量同步插件

**位置**: `src/plugins/sync-variable-plugin/`

**功能描述**:
当节点创建或更新时，自动将节点的输出定义（JsonSchema）同步到变量引擎，供其他节点引用。

**技术亮点**:
- **JsonSchema → AST 转换**: 将 JsonSchema 转换为抽象语法树（AST）表示
- **实时同步机制**: 监听节点创建和表单值变化事件，自动同步
- **类型系统**: 支持 object、array、string、number、boolean 等类型
- **事件驱动**: 基于插件化的事件驱动架构

**核心代码**:
```typescript
// JsonSchema 转 AST
export function createASTFromJSONSchema(jsonSchema: JsonSchema): ASTNodeJSON | undefined {
  switch (type) {
    case 'object':
      return ASTFactory.createObject({
        properties: sortProperties(jsonSchema.properties || {}).map(([key, _property]) => ({
          key,
          type: createASTFromJSONSchema(_property),
          meta: { description: _property.description },
        })),
      });
    case 'array':
      return ASTFactory.createArray({
        items: createASTFromJSONSchema(jsonSchema.items!),
      });
    // ... 其他类型
  }
}

// 监听节点创建，自动同步变量
flowDocument.onNodeCreate(({ node }) => {
  form.onFormValuesChange((props) => {
    if (props.name.match(/^outputs/) || props.name.match(/^title/)) {
      syncOutputs(form.getValueIn('outputs'));
    }
  });
});
```

**业务价值**: 支持配置字段的智能引用和类型提示

- 支持类型推导和验证

## 总结

本项目的核心价值在于通过**可视化配置编排**替代手动编写 JSON 配置，降低配置门槛，提升配置效率和正确性。技术上实现了复杂的图遍历、ID 去重、类型系统、表单验证等功能，展示了较强的前端工程化能力。
