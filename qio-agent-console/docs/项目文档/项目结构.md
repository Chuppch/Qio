## `src/` 目录包含的内容

### 核心业务代码
- `app.tsx` - 应用入口和路由配置
- `editor.tsx` - 工作流编辑器主组件
- `pages/` - 所有页面组件（11个页面）
- `components/` - 所有业务组件
- `nodes/` - 工作流节点定义（50个文件）
- `services/` - API 服务层（19个服务文件）
- `form-components/` - 表单相关组件

### 支撑代码
- `config/` - API 配置
- `context/` - React Context
- `hooks/` - 自定义 Hooks
- `utils/` - 工具函数
- `typings/` - TypeScript 类型定义
- `plugins/` - 编辑器插件
- `shortcuts/` - 快捷键处理
- `styles/` - 样式和主题
- `assets/` - 图标资源

## 根目录的其他文件

根目录主要是配置和构建相关：

- 配置文件：
  - `package.json` - 依赖管理
  - `tsconfig.json` - TypeScript 配置
  - `rsbuild.config.ts` - 构建配置
  - `index.html` - HTML 入口

- 构建和部署：
  - `build.sh`, `build-arm-amd.sh` - 构建脚本
  - `Dockerfile`, `docker-compose.yml` - Docker 配置
  - `push.sh` - 部署脚本

- 文档：
  - `docs/` - 文档和 SQL 脚本

- 静态资源：
  - `public/` - 仅包含 favicon.ico
