# Public assets

This directory contains repository-level visual assets shared by the root and
module documentation. Application runtime assets remain inside their owning
frontend projects.

```text
public/
├── brand/                 # Qio brand and repository hero artwork
└── previews/
    ├── qio-v1/            # Qio v1 feature and setup previews
    └── agent-hub/         # Agent Console interaction previews
```

Use repository-relative paths in Markdown. Add new documentation images to the
appropriate directory instead of linking to a retired repository or external
image host.
